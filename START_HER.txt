MINNANDEL 2.1 — SAMLET, AFGRÆNSET OPDATERING

VIGTIGT: Dette er en PATCH til din eksisterende MinnAndel-repo, ikke et helt nyt Expo-projekt.
Intet bliver pushet automatisk til GitHub eller Firebase. Ingen .env eller API-nøgler er med.

1. Tag backup først i din nuværende MinnAndel-mappe:
   git status
   git add .
   git commit -m "Backup foer MinnAndel 2.1"
   (Gør ikke dette, hvis dit git-status viser hemmelige nøgler eller .env under tracked files.)
2. Udpak ZIP og kopiér INDHOLDET af mappen MinnAndel_2_1_samlet_patch
   ind i den eksisterende MinnAndel-mappe. Erstat identiske filer og flet mapper.
3. BEHOLD FRA ORIGINALREPO:
   - din .env med den korrekte Firebase-webkonfiguration
   - index.js, assets/, app.json, package.json og package-lock.json.
   - slet IKKE dine egne brugerdata i Firebase.
   - ingen grund til at importere .env.example over din .env.
4. Tilføj følgende til projektets .gitignore, hvis det ikke allerede er gjort:
   .env
   .env.*
   !.env.example
   .firebase/
   functions/node_modules/
5. I en VS Code-terminal I PROJEKTETS RODMAPPE:
   npm install
   npx expo install firebase expo-camera @react-native-async-storage/async-storage @react-navigation/native @react-navigation/native-stack react-native-screens react-native-safe-area-context
6. Opdatér Firebase Security Rules (nyt: beboeren kan forespørge egne fejlmeldinger):
   npx firebase-tools login
   npx firebase-tools use --add         (hvis ikke tilsluttet i forvejen)
   npx firebase-tools deploy --only firestore:rules
7. Åbn din eksisterende .env. Tilføj denne ene linje, medmindre du allerede
   HAR DEPLOYET Cloud Function og vil betale for AI:
   EXPO_PUBLIC_AI_ENABLED=false
8. Genstart Expo HELT:
   npx expo start --clear
   Scan QR i Expo Go, eller genindlæs appen.

TEST I DENNE RÆKKEFØLGE:
  a) Bestyrelse: Log ind -> opret opslag og opgave -> log ud.
  b) Beboer: Log ind -> se opslag -> opret fejlmelding -> se Min status -> log ud.
  c) Vicevært: Log ind -> se fejlmelding -> skift status -> log ud.
  d) Beboer: Log ind -> se status ændret.
  e) Bestyrelse: Opret facilitet, opret kontakt, offentliggør tekstnote.
  f) Beboer: Book facilitet, søg kontakt, spørg dokumentopslag om note.
  g) Scan QR når equipment/drill01 findes i Firestore.

HVIS DET IKKE VIRKER: Del kun FEJLBESKEDEN (ikke API-nøgler/adgangskoder).
Den nye chat bruger gratis dokumentopslag, når AI ikke er aktiveret.
Firebase Authentication og Firestore skal stadig være opsat og fungere.
Ingen PDF-upload eller automatiske pushnotifikationer er implementeret.
